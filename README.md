## The word

> **quaslide** (n.) — when a laggy video call freezes you mid-lean-back and all stare at your open mouth. "I was quasliding, I swear I agreed."

## What it does

`main.py` writes the entry text to `$OUTPUT_DIR/entry.txt` (default `/output`).

## Run

```bash
python3 main.py
cat /output/entry.txt
```
